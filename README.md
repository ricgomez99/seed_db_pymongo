## Instrucciones

Para poder procesar datos hacia una base de datos debe contar con una url de mongo db atlas.

- Cree un archivo `.env` o `.venv` y agregue la variable `URL` con el valor de la url de conexión.

- Agregue el método `run_seed` al método `main` para poder hacer la inserción de los datos.

- Corra el programa con el comando:

```bash
uv run ./src/main.py
```
